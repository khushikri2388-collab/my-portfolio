# Khushi Kumari - Personal Portfolio

A beginner-friendly responsive portfolio made with HTML, CSS and JavaScript.

## Files
- `index.html` - website content and structure
- `style.css` - dark blue and purple design + responsive layout
- `script.js` - mobile menu, current year and back-to-top button

## Before publishing
1. Open `index.html` in a browser and check the website.
2. In `index.html`, replace `your-email@example.com` with your real email.
3. Replace the GitHub and LinkedIn profile links with your own profile URLs.
4. Check that your name, education, skills and project details are accurate.
5. Add more projects when you have them.

## Run locally
Open `index.html` in a browser. You can also open the folder in VS Code and use the Live Server extension if it is installed.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `khushi-portfolio`.
2. Upload `index.html`, `style.css` and `script.js` to the repository's root folder.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish the website. Refresh the Pages settings page if needed.
8. Open the live URL shown there. It will usually look like:
   `https://YOUR-GITHUB-USERNAME.github.io/khushi-portfolio/`
9. Test the link on your phone and laptop before submitting.
